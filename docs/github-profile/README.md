## About Me

I am a Computer Engineering student exploring frontend, backend, and database-driven web development. I like building practical systems, experimenting with interfaces, and turning ideas into working projects.

Right now, I am learning by building: student portals, organization websites, dashboards, CRUD systems, authentication flows, and small experiments that push my coding confidence forward.

I am still sharpening the fundamentals, but that is the fun part. Every project is another step in seeing how far curiosity, consistency, and vibe coding can take me.
